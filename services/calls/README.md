# SignTrack.Calls

Microservicio de **videollamadas y salas** (C# .NET 8).

## Estado: Scaffold (Sprint 2)

## Responsabilidades planeadas

- Crear/unir salas de videollamada
- Signaling WebRTC (SignalR o WebSocket)
- Historial de llamadas
- Integración con Identity (JWT)

## Ejecutar

```bash
dotnet run --project SignTrack.Calls.Api
```
